# push_swap

## Description(概要)

`push_swap` は、重複のない整数のリストを受け取り、2つのスタック(`a` と `b`)
を使って昇順にソートする **Push_swap 操作の列** を標準出力に表示するプログラムです。
ソート後は、最小の数がスタック `a` の先頭に来ます。

このプロジェクトの目的は、アルゴリズムの計算量を具体的に体験することです。
アルゴリズムのコストは CPU 時間ではなく、**生成した Push_swap 操作の数**で測ります。

バイナリには4つの戦略が組み込まれており、実行時に選択できます。

| フラグ       | 戦略                           | 計算量(操作数) |
|--------------|--------------------------------|------------------|
| `--simple`   | 選択ソートの応用               | O(n²)            |
| `--medium`   | チャンクソート(√n 個の範囲)  | O(n√n)           |
| `--complex`  | 基数ソート(LSD・2進数)       | O(n log n)       |
| `--adaptive` | disorder に応じて上記から選択(デフォルト) | 後述 |

## Disorder(無秩序度)

disorder は、**操作を行う前に1回だけ**、次の式で測定します。

```
disorder = mistakes / total_pairs
```

`mistakes` は、`i < j` かつ `a[i] > a[j]` となるペア `(i, j)` の個数、
`total_pairs` は `n(n-1)/2` です。
ソート済みなら `0`、逆順なら `1` になります。
計算に O(n²) の CPU 時間がかかりますが、Push_swap 操作ではないので、
操作数には数えません。

## Algorithms(アルゴリズム)

すべての戦略は、最初に各値を**ランク(`index`、`0` 〜 `n-1`)**に置き換えます。
ランクは「自分より小さい値の個数」を数えて求めます。
これは前処理であり、操作は生成しません。

### Simple — 選択ソート、O(n²)

<TODO: 自分の言葉で説明を書く>

1. 次の処理を `n` 回繰り返す: `a` の中で、残っている最小の要素を探す。
2. `a` を回転して(`ra` と `rra` のうち近いほう)その要素を先頭に出し、`pb` する。
3. 最後に `pa` で全部戻す。`b` には小さい順に積まれているので、
   戻した `a` は昇順になる。

**計算量:** `n` ラウンドそれぞれで、回転は最大 `n/2` 回、`pb` が1回。
最後の `pa` が `n` 回。平均で約 n²/8 + 2n 手なので、O(n²) 操作です。
追加の空間は、スタックの `n` 個のノードを除いて O(1) です。

### Medium — チャンクソート、O(n√n)

<TODO: 自分の言葉で説明を書く>

1. **分配:** `b` に送った個数を `pushed`、チャンクの大きさを `c ≈ √n` とする。
   `a` の先頭のランクを見て、次のように操作する。
   - ランク `<= pushed` : `pb` のあとに `rb`(`b` の底へ送る)
   - ランク `<= pushed + c` : `pb`
   - それ以外 : `ra`(今回は飛ばす)
2. **回収:** `b` が空になるまで、`b` の最大要素を先頭に出し(`rb` / `rrb`、
   近いほう)、`pa` する。

**計算量:** 手順1では `n` 個を `b` に送る。飛ばす操作は `ra` 1回で、
窓の大きさが `√n` なので、1回の `pb` あたりの飛ばす回数は約 `√n` 回。
手順2でも `n` 個を戻し、最大値は直近のチャンクの中にあるので、
回転は1個あたり約 `√n` 回。合計は O(n√n) です。追加の空間は O(1)。

### Complex — 基数ソート(LSD・2進数)、O(n log n)

<TODO: 自分の言葉で説明を書く>

ランクの下位ビットから上位ビットへ、`⌈log₂ n⌉` 個のビットについて、
それぞれ次を行います。

1. `a` の `n` 個の要素について: ビット `i` が `0` なら `pb`、`1` なら `ra`。
2. `b` の要素を全部 `pa` で `a` に戻す。

**計算量:** 1パスは `n` 手(`pb` または `ra`)に加えて、最大 `n` 回の `pa` なので、
最大 `2n` 手。パス数が `⌈log₂ n⌉` なので、合計は O(n log n) 操作
(平均で約 1.5 n log₂ n)です。入力の順序にほとんど左右されません。
追加の空間は O(1) です。

## Project structure(ファイル構成)

|----------|------|
| `main.c` | エントリポイント、戦略の振り分け |
